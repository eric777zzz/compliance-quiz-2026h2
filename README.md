# 2026 H2 遵法及專知互動測驗

開啟 `index.html` 即可使用，無須安裝或連線。150 題按原題號分成 3 卷，每卷 50 題、滿分 100 分。

- 單選及複選作答；複選須完全符合題庫答案，每題 2 分。
- 交卷後顯示成績、正確答案與題庫出處，可篩選錯題和未答題。
- 三卷各自保存作答進度於瀏覽器，可重新作答及列印。
- 手機與桌面適用。答案包含於網頁原始碼，適合練習使用。

題目與答案依提供的原始題庫，未另行驗證法規時效。公開網頁未包含原始聯絡窗口欄位。作答資料不會傳送至伺服器。

GitHub Pages：在儲存庫 Settings → Pages，選擇 Deploy from a branch，指定 main / root。
